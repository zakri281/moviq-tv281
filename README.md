# MOVIQ TV — сайт для GitHub Pages

Готовый статический сайт телеканала: адаптивный дизайн, оригинальный SVG-логотип, секции прямого эфира, программа, новости, информация о канале и контакты.

## Файлы
- `index.html` — структура сайта
- `style.css` — дизайн и адаптация под мобильные устройства
- `script.js` — меню и загрузка плеера
- `assets/moviq-logo.svg` — оригинальный векторный логотип

## Подключение VK Видео
Сейчас сайт содержит ссылку на эфир:
`https://vkvideo.ru/live-231787809_456239198`

Ссылка на страницу трансляции и ссылка для встраивания плеера — не всегда одно и то же. Чтобы включить встроенное воспроизведение:

1. Открой трансляцию в VK Видео.
2. Найди меню «Поделиться» и пункт «Код для вставки» / «Встроить» (название может отличаться).
3. Скопируй код iframe, который выдаёт VK.
4. Возьми значение `src="..."` из этого кода.
5. Открой `script.js` и вставь адрес в `VK_EMBED_URL`, например:
   ```js
   const VK_EMBED_URL = "ВСТАВЬ_СЮДА_URL_ИЗ_SRC";
   ```
6. Сохрани и загрузи обновлённый `script.js` в GitHub.

Если VK не предлагает код встраивания или ограничивает его для этой трансляции, посетители смогут открыть эфир по кнопке «Открыть на VK Видео», но встроенный плеер может быть недоступен. Не используй самостоятельно придуманный embed URL — он должен быть выдан VK.

## Перед публикацией
- Замени демонстрационный email `hello@moviq.tv` в `index.html` на реальный адрес.
- Обнови программу передач и новости под реальные данные канала.
- Проверь, что у тебя есть права на показ всего контента, который транслируется.

## Публикация на GitHub Pages
1. Войди в GitHub: https://github.com/
2. Нажми **New repository**. Назови репозиторий `moviq-tv` и создай его (Public).
3. Загрузи в корень репозитория `index.html`, `style.css`, `script.js`, `README.md` и папку `assets`.
4. Открой **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Deploy from a branch**.
6. В качестве ветки выбери `main`, папку `/ (root)`, затем нажми **Save**.
7. Подожди завершения публикации. Ссылка будет примерно такой:
   `https://ТВОЙ-ЛОГИН.github.io/moviq-tv/`

Если хочешь адрес `https://ТВОЙ-ЛОГИН.github.io/` без `/moviq-tv/`, назови репозиторий ровно как свой GitHub-логин с окончанием `.github.io`.
